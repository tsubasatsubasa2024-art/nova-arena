NOVA ARENA 操作ガイド

【PC操作】

・W / A / S / D：8方向移動（斜め移動も等速に最適化）

・マウスカーソル：360度精密照準

・左クリック長押し：連射通常攻撃

・Spaceキー：急速ダッシュ（残像＆回避）

・Eキー：必殺技（ダメージ蓄積で発動可能）

・Q / Fキー / 右クリック：エネルギーコア独自アビリティ発動

・ESCキー：ポーズメニュー

【スマホ・タブレット操作】

・画面左側スティック：自由移動

・画面右側スティック：照準決定＆自動射撃

・DASH / SUPERボタン：各種アクション即時発動

【独自要素：エネルギーコア】

マップ中央や各所に出現する光るコアを回収してゲージを100%にすると、戦況に応じた2つの強化が発動可能になります。

・A: OVERRIDE DASH：次回ダッシュ距離2倍＋無敵時間付与

・B: PULSE SHIELD：5秒間被ダメージ50%カット＋周囲反発パルス
